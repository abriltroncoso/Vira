# Vira Studio

Landing de una sola página para el estudio creativo **Vira Studio**. React + Vite. Toda la navegación es scroll en la home.

## Requisitos

Node.js 18 o superior ([nodejs.org](https://nodejs.org)).

## Cómo correrlo

```bash
cd vira-studio
npm install
npm run dev
```

Abrí la URL que imprime Vite (por lo general `http://localhost:5173`).
